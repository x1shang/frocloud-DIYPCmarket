# frocloud · DIYPCmarket

> 一份装机市场调研表。把显卡、CPU、内存、机箱散热电源的价格与用料，
> 压成九张可以横向对比的「天梯图」—— 数据全都活在一个 Excel 工作簿里。

## 📊 九张工作表

| 工作表 | 内容 |
|---|---|
| `GPU天梯图` | 显卡性能分层，按 3DMark 的 TIME SPY / Port Royal / Steel Nomad 分项与总分排序 |
| `CPU天梯图` | 桌面 CPU 性能排序 |
| `笔记本CPU天梯图` | 移动端 CPU 排序（Ultra、AI Max、HX 系列等） |
| `50系显卡用料` | RTX 50 系各型号用料对比；**内含一张「配置与预算」饼图** |
| `2025显卡` | 当季在售显卡整理 |
| `2025CPU` | 当季在售 CPU 整理 |
| `显卡品牌` | 品牌与产品线对照 |
| `内存` | 内存规格与价位 |
| `机箱散热电源` | 机电散三件套 |

「天梯图」的写法不是堆跑分，而是一把五档的实用尺子：

```text
胜任  →  好用  →  能用  →  可运行  →  无法使用
```

不问跑分有多高，只问**能不能跑得动你要跑的东西**。

## 🧭 怎么用

1. 先在「天梯图」里定位目标档位 —— 比如"能跑 3A 中画质"或"够用就行"
2. 再去 `2025显卡` / `2025CPU` / `机箱散热电源` 按预算挑具体型号
3. 同档位之间的差异，看 `50系显卡用料` 与 `显卡品牌`

## ⚠️ 必须知道的一个坑：Office / WPS 锁文件

打开 `frocloud.xlsx` 时，Office 和 WPS 都会在同目录生成一个 `~$frocloud.xlsx`
（约 165 字节）。它是**锁**，不是数据，关闭工作簿后自动消失。

它曾经被误提交进仓库（提交 `24d106c`），现已停止跟踪，`.gitignore` 里的 `~$*` 负责挡住它。

> [!warning] 别去手工删正在使用中的 `~$` 文件
> 关闭 WPS/Excel 后它会自己消失。只有在**确认相关程序已退出**、
> 它却还孤零零留着时，那才是异常退出的残骸，可以安全删除。

## 🔧 更新流程

工作簿是二进制，git 看不出"改了哪一格"，每次保存都是整个文件的新版本。所以流程简单点：

1. 用 WPS / Excel 编辑 `frocloud.xlsx`
2. **关闭工作簿**（让 `~$` 锁文件消失）
3. `git add frocloud.xlsx && git commit`

> [!tip] 想给 `.xlsx` 挂 Git LFS
> 如果以后工作簿明显变大、又希望历史轻一些，可以给它加 LFS。
> 本机 `git-lfs 3.7.1` 已随 Git 安装、系统级 filter 已注册，开箱可用：
> 新建 `.gitattributes`，写 `*.xlsx filter=lfs diff=lfs merge=lfs -text`。
> 目前 62 KB，还没有必要。
